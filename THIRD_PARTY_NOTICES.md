# Third-party visual assets

JevMate uses bundled Geist Variable and Geist Mono Variable fonts (SIL Open Font License 1.1) via Fontsource, and Phosphor React icons (MIT). The corresponding license files are shipped in `web/public/licenses/` and deployed under `/licenses/`.

- Geist: https://github.com/vercel/geist-font
- Fontsource: https://fontsource.org/
- Phosphor: https://github.com/phosphor-icons/react

The geometric pixel bot in `web/Bot.tsx` and the matching favicon were authored for this project and are covered by its MIT license.
